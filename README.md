# Biopython-sequence-analysis
Python-based DNA sequence analysis using Biopython, including ORF identification, sequence statistics and repeat analysis.
## Features

- Multi-FASTA file processing
- DNA sequence length analysis
- Longest and shortest sequence identification
- ORF identification across reading frames
- DNA repeat analysis

## Technologies

- Python
- Biopython
- FASTA
